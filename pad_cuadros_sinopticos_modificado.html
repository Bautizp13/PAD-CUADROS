Microorganismos

Modo repaso

Deslizar bacterias

Deslizá (con el mouse, el dedo o las flechas del teclado ← →) para pasar de una bacteria a la siguiente. Usá los filtros para armar tu propia secuencia de repaso.

Modo repaso

Modo estudio

Mirá el nombre, pensá el cuadro completo antes de revelarlo, y marcá si ya lo sabés o si necesitás repasarlo. Tu progreso se guarda por microorganismo.

Modo repaso

Comparar microorganismos

Elegí los microorganismos que quieras para verlos lado a lado, campo por campo. Ideal para diferenciar bacterias parecidas antes de un parcial. ¡Ahora podés comparar sin límites!

Herramientas

Agregar contenido

Pegá acá el código HTML de uno o varios microorganismos generado con el prompt maestro (cada uno es un bloque <article data-module-type="...">, con data-module-type igual a bacteria, virus, parasito o hongo). Podés pegar varios bloques juntos para importar varios de una sola vez. Si uno ya existe (mismo nombre y tipo), se actualiza en vez de duplicarse.
